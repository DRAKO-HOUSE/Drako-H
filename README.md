# DRAKO HOUSE - Cardápio Online

Este é um projeto de cardápio online para a lanchonete DRAKO HOUSE. Ele permite que os clientes visualizem os produtos, montem seus pedidos e finalizem a compra através do WhatsApp.

## Funcionalidades

- **Cardápio dinâmico:** Os produtos são carregados a partir do Firebase, permitindo que o administrador adicione, edite e remova itens em tempo real.
- **Carrinho de compras:** Os clientes podem adicionar e remover produtos do carrinho, que calcula o total do pedido.
- **Seleção de sabores:** Para produtos como combos, o cliente pode escolher os sabores de sua preferência.
- **Cálculo de frete:** O sistema calcula a taxa de entrega com base no bairro do cliente.
- **Finalização via WhatsApp:** O pedido é enviado para o WhatsApp do estabelecimento com todas as informações necessárias.
- **Painel administrativo:** Um painel de administração protegido por senha permite que o proprietário da loja gerencie os produtos, o status da loja (aberta/fechada) e outras configurações.
- **Suporte a mídia:** O sistema suporta a exibição de imagens e vídeos dos produtos.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Firebase Realtime Database**

## Como Usar

1.  Abra o arquivo `index.html` em seu navegador.
2.  Navegue pelas categorias de produtos.
3.  Adicione os produtos desejados ao carrinho.
4.  Clique em "Finalizar via WhatsApp" para montar seu pedido.
5.  Preencha seus dados de entrega e forma de pagamento.
6.  Clique em "Confirmar e Enviar Pedido" para ser redirecionado ao WhatsApp com a mensagem do seu pedido.
